# Day 5 – Introduction to SIEM (Security Information and Event Management)

## 🎯 Objective

Today I completed the **SIEM** room in the TryHackMe SOC Level 1 path. The goal was to understand what a SIEM is, how it collects and analyzes logs, and why it is one of the most important tools used by SOC analysts.

---

# 🛡️ What is SIEM?

**SIEM (Security Information and Event Management)** is a security solution that collects, stores, correlates, and analyzes logs from multiple devices and applications in a centralized platform. It helps security teams detect suspicious activities, investigate incidents, and respond to threats more efficiently.

Instead of checking logs from every device individually, a SOC analyst can monitor all security events from one dashboard.

---

# 📄 Logs Everywhere

Every device and application in an organization generates logs that record user activities, system events, and security-related actions.

Common log sources include:

* Operating Systems
* Servers
* Firewalls
* Routers and Switches
* Web Applications
* Databases
* Antivirus and EDR Solutions
* Cloud Services
* Authentication Services

These logs help SOC analysts understand what is happening across the organization's environment.

---

# 💻 Host-Centric Log Sources

Host-centric logs are generated directly from endpoints and servers.

Examples include:

* Windows Event Logs
* Linux System Logs
* Authentication Logs
* Application Logs
* Endpoint Detection and Response (EDR) Logs
* Antivirus Logs

These logs help analysts investigate activities occurring on individual systems, such as user logins, process creation, software execution, and file modifications.

---

# 🌐 Network-Centric Log Sources

Network-centric logs are generated by network devices that monitor and control traffic.

Examples include:

* Firewall Logs
* IDS/IPS Logs
* Router Logs
* Switch Logs
* VPN Logs
* DNS Logs
* Proxy Logs
* Web Server Logs

These logs help identify network attacks, suspicious connections, unauthorized access attempts, and unusual traffic patterns.

---

# ⚙️ Features of SIEM

Modern SIEM platforms provide several important capabilities:

* Centralized log collection
* Log normalization and correlation
* Real-time monitoring
* Threat detection
* Alert generation
* Log searching and investigation
* Dashboards and reporting
* Long-term log storage
* Compliance support

These features allow SOC analysts to investigate incidents faster and gain better visibility across the environment.

---

# 📥 Log Sources & Ingestion

Before analysis can begin, logs must be collected and sent to the SIEM.

The basic log ingestion process is:

**Log Sources → Log Collection → Parsing & Normalization → SIEM Storage → Analysis**

During ingestion, logs from different devices are converted into a common format so they can be searched, correlated, and analyzed together.

---

# 🚨 Alerting Process

After logs are collected, the SIEM continuously analyzes them using detection rules and correlation techniques.

The process typically follows these steps:

1. Collect logs from multiple sources.
2. Normalize and store the logs.
3. Apply detection rules and correlation.
4. Identify suspicious activity.
5. Generate an alert.
6. Send the alert to the SOC analyst for investigation.

This allows analysts to quickly identify potential security incidents without manually reviewing every log.

---

# 🔍 Alert Analysis

When an alert is generated, the SOC analyst begins an investigation by:

* Reviewing the alert details
* Examining related logs
* Correlating events from different sources
* Determining whether the alert is a true or false positive
* Assessing the impact
* Escalating or responding if necessary

Alert analysis is one of the primary daily responsibilities of a SOC Analyst.

---

# 🧠 Key Takeaway

Today's lesson showed me that **SIEM is the central platform used in a Security Operations Center**. It collects logs from across an organization's infrastructure, correlates events, detects suspicious activities, and generates alerts that help analysts identify and respond to threats efficiently.
